## Review rules established
- Salt/pepper to taste → omit from ingredients (include only if measured, e.g. "1 tsp salt")
- ~10 min and "about 10 min" are synonymous → no flag needed
- Oven temps 300–475 → assume °F, add unit automatically ("325°F" not "325 degrees F" or "325°")
- Use `processing:` (list) not `preparation:` or notes for prep info (julienned, chopped, beaten, etc.)
- `yields:` not `yield:` (plural); `unit: servings` not `unit: serving`
- X-original-source must have `../originals/` prefix and `.jpg` extension (lowercase)
- Optional serving suggestions (sour cream, guacamole) → move to `notes:`, not ingredients
- Source URL: add when known; leave generic if only domain available
- Ingredient names: strip embedded prep info (e.g. "onion, chopped:" → `onion:` + `processing: [chopped]`)
- Ingredient units: pluralize where appropriate (cup → cups, can → cans, slice → slices)
- Empty `X-flags: []`, `X-dietary: []` → remove
- Null time fields (X-total_time: null) → remove
- Cajun/seasoning mix prefixes in ingredient names → flatten to plain ingredient names
- `note:` (singular) → `notes:` (plural)
- `amounts: [amount: null, unit: null]` → `amounts: []` for unknown quantities
- `preparation:` → `processing:` throughout
- Unit abbreviations: lb→pounds, tbsp→tablespoons, tsp→teaspoons, cup→cups, mins→minutes
- Decimal fractions → quoted strings where cleaner (0.333→"1/3", 1.333→"1 1/3")
- `prep_time:`/`cook_time:`/`cuisine:` (bare, no X-) → add `X-` prefix or remove
- Optional toppings/garnishes as ingredient entries → move to `notes:`
- `X-notes:`, `X-description:` → drop X- prefix (`notes:`, `description:`)
